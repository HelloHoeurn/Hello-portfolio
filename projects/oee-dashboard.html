Live OEE Tracking & Line Balancing Engine

A technical overview of parsing floor telemetry and syncing it to corporate performance expectations.

The Problem

Production parameters were manually calculated across disparate files, leading to inaccurate capacity estimations, missed manufacturing line-balancing opportunities, and an extreme data blindspot between shop-floor adjustments and the active ERP.

The Engineered Solution

Leveraged advanced **Excel Power Query** functions to pipeline multi-source shift tracker documents directly into clean data flows. Engineered custom data architectures utilizing dynamic Pivot Tables to map out precise time-studies, calculate strict operational capacities, and ensure structural manpower setups align immediately with active targeting.

Key Outcomes

  • Eliminated manual tracking processing lag.
  • Configured flexible systems capable of handling rapid item intakes and line changeovers smoothly.
  • Provided clean visual structures mapping live floor performance back directly against the core BOM logic.
